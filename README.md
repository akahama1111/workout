# Workout Timer Builder

ワークアウト動画のURLをGemini APIでメニュー化し、好きなYouTubeを流しながら使う自分用タイマーです。

## 使い方

1. Gemini APIキーを入力
2. ワークアウト動画URLを入力
3. 必要なら流したいYouTube URLを入力
4. メニューを抽出
5. ワークアウト開始

APIキーはブラウザのlocalStorageに保存されます。コードやGitHubには保存されません。

## GitHub Pages

1. GitHubでリポジトリを作成
2. このフォルダのファイルをpush
3. `Settings > Pages` を開く
4. `Deploy from a branch` を選択
5. `main` ブランチの `/root` を選択
6. 発行されたURLをスマホで開く

このサイトはURLを知っている人なら開けます。自分用運用ではURLを共有しない前提です。
